## What’s new

- **Finder drag and drop.** Fixes Altillo’s transparent panel intercepting file drags intended for windows underneath it, including drag-to-install layouts in DMGs. A drag away from the notch now passes through to Finder, and leaving the visible drop target restores the destination underneath even while the notch remains expanded.
- **Shelf drops still work.** The notch receives the drag when it reaches the visible target, including when the target expands under a stationary pointer.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

If an older Altillo version prevents dragging the update to Applications, quit
Altillo first, then copy the new app and reopen it.

## Known limitations

- Apps that open one of their own windows keep it where they put it.
- Showing icons as they look in the menu bar needs Screen Recording; without it the Drawer shows each app’s icon.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.10.7 and disable automatic
updates temporarily in Settings → About. Your local Altillo data is kept unless
you explicitly remove it.

## Support

If something fails, use **Settings → About → Report a Problem** and include the
version, build and redacted diagnostics.
