# Preliminary trademark screening: Altillo

Date: 26 September 2026
Scope: word marks containing `ALTILLO`, Nice classes 9 and 42
Source: [EUIPO/EUIPN TMview](https://www.tmdn.org/tmview/)

This is a product-name screening, not a legal clearance opinion. TMview itself
warns that it is not an official register and that its information has no legal
effect. Before filing the mark or committing meaningful launch spend, an IP
professional should run similarity, figurative-mark and common-law searches.

## Result

- Class 9 returned five marks containing the string. They were `SALTILLO`,
  `PRC-SALTILLO` or `GRUPO INDUSTRIAL SALTILLO`; no exact `ALTILLO` result was
  present in the result set.
- Class 42 returned ten marks containing the string. The only short exact-word
  conflict was `EL ALTILLO`, Argentina INPI application `2855982`, registered
  since 11 September 2008. Other hits were longer `SALTILLO` or
  `ESTUDIO ALTILLO BOUTIQUE CREATIVA` marks outside Spain/EU.
- The unfiltered search contains Spanish `ALTILLO` registrations in unrelated
  classes (for example OEPM `M2982929`, class 43). No exact Spanish or EU mark
  in class 9 or 42 appeared in the filtered results reviewed on this date.

## Product decision

Continue using **Altillo** for the current release: this preliminary screen did
not expose a blocking exact mark in the relevant classes and territory. Do not
describe the name as legally cleared or registered. Before a paid campaign or
an EUIPO/OEPM filing, commission a professional search that includes phonetic
similarity, logos, unregistered use and the precise goods/services wording.
