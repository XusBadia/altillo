Features — try them

Everything,
one hover away.

A Mac you can play with. Hover the notch, drag a file up, answer Claude. Nothing here is real except the music.

  1. Following along paused ·

  2. Shelf

    Drop a file on the notch. Pick it up in another window.

    A temporary place for the file you’ll need in a moment.

    Drag a file from Finder up to the notch.

  3. AI usage

    Claude, Codex, Cursor, Gemini, Copilot and five more.

    Your quota, your pace, and when it refills — at a glance.

  4. Live agents

    “Claude Code wants to run git push.”

    Approve or deny from the notch without leaving what you’re doing.

    Allow it, deny it, or hold for the risky ones.

  5. Calendar

    Your next meeting and a Join button, right up top.

  6. Now playing

    Pause, skip, see what’s on.

    No app switching.

    Press play. The music is real.

  7. Mirror

    A quick look at yourself before the call.

    No camera here: the glass shows a drawing.

  8. Ask

    An assistant that runs on your Mac.

    Answering from your calendar and clipboard. On-device by default; web search only when you allow it.

  9. Drawer

    Tuck away the menu bar icons you don’t need to see.

    Hides icons on macOS 26 and needs Accessibility access. On macOS 27 they stay in the menu bar.

How it’s made

Quiet, private, yours.

i.

Private by design

Usage checks go straight to each provider with the credential its own tool already stores. No Altillo servers.

ii.

Native

Built in Swift for macOS 26. Light on battery, quiet when idle.

iii.

Yours to shape

Choose which modules appear and in what order.
