## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
