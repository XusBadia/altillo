## What’s new

- **AI usage, easier to compare.** Providers now share a single panel with aligned rows, progress bars and clear status messages.
- **Room for the whole message.** Narrow windows stack the details, and longer lists scroll vertically instead of cutting off provider cards. Plan names, reset times and warnings can wrap onto multiple lines.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Smaller panel sizes and long provider lists may require vertical scrolling.
- Usage availability and freshness depend on each provider. Cached readings
  remain marked when they are stale or a refresh fails.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.10.1 and disable automatic
updates temporarily in Settings. Your local Altillo data is kept unless you
explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
