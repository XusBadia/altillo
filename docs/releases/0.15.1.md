## What’s fixed

- Moving an icon into the Drawer hides it from the menu bar right away again. On some Macs a stalled screen capture kept new Drawer icons visible in the menu bar until Altillo restarted.

## Install or update

Use **Altillo → Check for Updates…** or download the signed, notarized DMG below.

## Rollback and support

To roll back, quit Altillo, install [0.15.0](https://github.com/XusBadia/altillo/releases/tag/v0.15.0) and temporarily turn off automatic updates in **Settings → General**. For help, use **Altillo → About → Report a Problem** and include the version and redacted diagnostics.
