# Desde el altillo

Three original instrumental demo tracks credited to **Estudio Altillo**, a fictional
artist created for this website. These are complete playable miniatures, not links
to Apple Music or Spotify. No copyrighted recordings or external samples are used.

| File | Title | Tempo | Approx. duration |
| --- | --- | --- | --- |
| `azotea.mp3` | Azotea | 82 BPM | 50 s |
| `luz-de-tarde.mp3` | Luz de tarde | 76 BPM | 54 s |
| `ultimo-tranvia.mp3` | Último tranvía | 86 BPM | 48 s |

Composed and synthesized for Altillo on 2026-09-20 with the reproducible script
`website/scripts/generate-demo-music.py` (Python 3 + NumPy + FFmpeg). Electric piano,
soft pads, synthesized bass and swung percussion are generated mathematically.
Each piece has an introduction, 16 bars with a repeating four-chord progression,
an original melody and a fading outro. No ElevenLabs service was used.

Encoding: stereo MP3, 44.1 kHz, 128 kbps. Mastering targets −18 LUFS with −1.5 dBTP
ceiling. Playback should begin only after a user interaction.

The compositions, synthesis script and rendered recordings are provided under the
repository's MIT license.
