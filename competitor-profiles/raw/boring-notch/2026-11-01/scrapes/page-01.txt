L38: ## Installation
L39: 
L40: **System Requirements:**
L41: - macOS **14 Sonoma** or later
L42: - Apple Silicon or Intel Mac
L43: 
L44: ---
L45: ### Option 1: Download and Install Manually
L46: 
L47: <a href="https://github.com/TheBoredTeam/boring.notch/releases/latest/download/boringNotch.dmg" target="_self"><img width="200" src="https://github.com/user-attachments/assets/e3179be1-8416-4b8a-b417-743e1ecc67d6" alt="Download for macOS" /></a>
L48: 
L49: Once downloaded, open the `.dmg` and move **Boring Notch** to your `/Applications` folder.
L50: > [!IMPORTANT]
L51: > We don't have an Apple Developer account (yet 👀), so macOS will warn you that Boring Notch is from an unidentified developer on first launch. This is expected behavior.
L52: >
L53: > You'll need to bypass this before the app will open. You only need to do this once. Use one of the methods below.
L54: 
L55: ---
L56: #### Recommended: Terminal (Always Works)
L57: 
L58: This is the quickest and easiest method. It only requires a single command and works consistently for all users. System Settings can sometimes fail and won't work for non-admin users.
L59: 
L60: After moving Boring Notch to your Applications folder, run:
L61: 
L62: ```bash
L63: xattr -dr com.apple.quarantine "/Applications/Boring Notch.app"
L64: ```
L65: 
L66: Then open the app normally.
L67: 
L68: ---
L69: #### Alternative: System Settings
L70: 
L71: > [!NOTE]
L72: > This method doesn't work for all users. If this doesn't work, use the Terminal method above.
L73: 
L74: 1. Try to open the app — you'll see a security warning.
L75: 2. Click **OK** to dismiss it.
L76: 3. Open **System Settings** > **Privacy & Security**.
L77: 4. Scroll to the bottom and click **Open Anyway** next to the Boring Notch warning.
L78: 5. Confirm if prompted.
L79: 
L80: ---
L81: ### Option 2: Install via Homebrew
L82: 
L83: You can also install using [Homebrew](https://brew.sh). The Homebrew installation automatically bypasses the macOS security warning described above.
L84: 
L85: ```bash
L86: brew install --cask TheBoredTeam/boring-notch/boring-notch
L87: ```
