## What’s new

- **Drawer icons hide and open reliably.** Fixed a race that could discard a successful response from macOS and leave selected icons in the menu bar. Verified with Slack and Telegram on a MacBook running macOS 27.0.1.
- **Rapid changes keep the latest state.** Older hiding requests no longer overwrite a newer choice when moving several apps, showing hidden icons or turning hiding off.
- **Safer menu clicks.** Altillo ignores hidden icons parked outside the menu bar instead of clicking the desktop or an app below it. Failed menu openings now show an explanation.
- **Better support diagnostics.** Settings → About → Copy Safe Diagnostics includes Drawer permissions, hiding state and item counts, without app names, menu contents or logs.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple. If you installed the private Drawer test
build, replace it with this DMG once to restore normal automatic updates.

## Known limitations

- Hiding menu bar icons requires macOS 27. On macOS 26, Drawer lists and opens icons while keeping them in the menu bar.
- Accessibility access is required. Apps that do not expose a usable menu or cannot be reached in the menu bar may still need to be opened directly.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.12.0 and disable automatic
updates temporarily in Settings → About. Your local Altillo data is kept.

## Support

If something fails, use **Settings → About → Report a Problem** and include
the output of **Copy Safe Diagnostics**.
