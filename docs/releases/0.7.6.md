## What’s new

- Release builds no longer expose internal drag-and-drop spike tools, and
  diagnostics redact paths, credentials and user content by default.
- The privacy contract now explains exactly when Altillo talks to Anthropic,
  OpenAI or another selected provider, and distinguishes that traffic from
  data sent to Altillo (none).
- Agent hooks remain optional. Settings explains what passive detection can do,
  what interactive hooks add, and how to review, back up and remove only the
  fragments owned by Altillo before uninstalling the app.
- About now includes privacy, support and copyable redacted diagnostics with
  the exact app version and build.
- Every future release is gated by the Swift, macOS, localization and website
  suites, then smoke-tested from the exact signed and notarized DMG.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- On macOS 27, Drawer can catalog, move and open menu-bar items but cannot hide
  them; hiding remains available on macOS 26.
- The automated suites and the virtual-island path were verified for this
  release. The complete acceptance matrix still needs a separate pass on a
  MacBook with a physical notch and macOS 26.
- Passive Claude Code and Codex detection works without hooks, with less precise
  state. Allow/deny and replying from Altillo require the optional native hook
  integration for each CLI.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it. Before deleting Altillo,
use **Settings → Agents → Prepare to Uninstall** if you installed agent hooks.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
