## What’s new

- **Real menu bar icons in the Drawer.** Allow Screen Recording (optional, in
  **Settings → Drawer** or during setup) and the Drawer shows each icon exactly
  as it looks in your menu bar, even while it's hidden. Altillo only captures
  the menu bar. Without it, the Drawer keeps showing each app's icon.
- **Every hidden icon opens its own menu.** When an app doesn't offer a
  standard menu, Altillo shows its icon in the menu bar for a moment and clicks
  it, so the app opens its menu or panel exactly as it does from the menu bar.
  When you close it, the icon hides again. This fixes icons that did nothing,
  or opened the app's window instead of its menu.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- An icon captured while hidden can't be refreshed until it's visible again,
  so a hidden icon shows its last look.
- After a menu opened this way closes, macOS shows every Drawer icon for about
  a second before hiding them again.
- An icon macOS can only place behind the notch can't be clicked; Altillo then
  opens it through Accessibility, as before.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
