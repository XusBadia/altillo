# Altillo brand assets

`AltilloIconMaster-11A.png` is the canonical app-icon artwork selected for Altillo. The PNGs in `AppIcon.appiconset` are direct Lanczos downscales of this file; do not regenerate them from the SVG.

`AltilloMark.svg` is a simplified vector companion used only where a monochrome or resolution-independent mark is required, such as the menu-bar template icon.
