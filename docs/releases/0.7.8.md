## What’s fixed

- Drawer now reveals an auto-hidden menu bar before beginning its native
  Command-drag. On a MacBook, the previous gesture could hit the window below
  while the menu bar was still appearing, briefly move the pointer, and then
  report that macOS had rejected the icon.
- Moving an icon out of Altillo now retries with Altillo’s own menu-bar chrome
  temporarily compacted on macOS 27 as well as macOS 26. This gives the
  narrower area beside a physical notch enough room to accept the icon.
- Command remains held until WindowServer has consumed mouse-up, avoiding an
  intermittent snap-back when the system is busy.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Support

If a menu-bar icon still refuses to move, use **Altillo → About → Report a
Problem** and include the version, build and redacted diagnostics.
