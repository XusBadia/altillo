## What’s new

- **Settings with room to breathe.** A persistent sidebar separates app-wide settings from the options for each section. General covers opening, displays, haptics and automatic glances; Appearance brings together width, side indicators and starting layouts.
- **One page per section.** Shelf, Ask, Calendar, Usage, Clipboard and Agents each have their own settings page. Section visibility and ordering stay together, with direct links to configuration. Disabled sections remain configurable, including removing installed agent hooks.
- **A more flexible window.** Settings can be resized, with independent scrolling and the existing keyboard shortcuts. Contextual settings links open the matching page, and all new text is available in Spanish.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Apps that open one of their own windows keep it where they put it.
- Showing icons as they look in the menu bar needs Screen Recording; without it the Drawer shows each app’s icon.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.10.6 and disable automatic
updates temporarily in Settings → About. Your local Altillo data is kept unless
you explicitly remove it.

## Support

If something fails, use **Settings → About → Report a Problem** and include the
version, build and redacted diagnostics.
