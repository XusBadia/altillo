## What’s new

The Drawer is rebuilt from scratch for macOS 27: the icons you keep in Altillo
now really leave the menu bar.

- **Hidden for real, instantly.** Drawer icons disappear from the menu bar the
  moment you move them, using macOS 27's own menu bar allow-list. No divider,
  no arrow, no empty gap, and nothing is dragged around behind your back.
- **Per app.** All the icons of an app move and hide together; Settings
  highlights them as a group. macOS's own items (clock, Wi‑Fi, Control
  Center) stay in the menu bar and say so.
- **Only Accessibility.** Screen Recording is no longer needed. Grant access
  with the button, or drag Altillo's icon straight into the Accessibility list
  in System Settings.
- **Show hidden icons** puts them back in the menu bar for a while, from
  Settings or Altillo's menu; **Hide them again** tucks them away.
- **New menu bar icons** can stay in the menu bar (default) or go straight to
  the Drawer.
- Quitting Altillo, turning the Drawer off or removing Accessibility brings
  every icon back.
- Settings has one visual hierarchy across all panes, and its option cards
  unfold with a gentle animation.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Hiding needs macOS 27. On macOS 26 the Drawer still lists your icons and
  opens their menus, but they stay in the menu bar.
- Icons hide by app, not one by one.
- While Drawer icons are hidden, macOS also hides icons from apps that aren't
  run from the Applications folder or aren't properly signed, and Live
  Activity pills in the menu bar. **Show hidden icons** or quitting Altillo
  brings them back.
- Moving an app into the Drawer shows every icon for about a second before
  macOS hides it again.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it. Apps you put in the
Drawer in 0.9.0 aren't known to 0.8.0, which starts with an empty Drawer.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
