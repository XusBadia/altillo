## What’s fixed

- Drawer works on a MacBook whose menu bar is already full beside the notch.
  macOS 27 folds new menu-bar items into its overflow (`«`), so Altillo’s
  divider and arrow were created out of sight and every move failed with
  “macOS couldn’t move this icon”. Altillo now detects a folded divider and
  places its controls beside the leftmost visible icon, verifying that they
  are visible before moving anything.
- Icons that macOS keeps in the overflow because they don’t fit beside the
  notch now appear in the Drawer, where their menus can be opened.
- After a crowded move, Altillo’s arrow returns to the right of the divider
  on macOS 27 instead of landing in the overflow.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- If the menu bar has no visible room at all, the divider can stay folded;
  Drawer settings then asks you to close an unused menu bar app.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
