## What’s new

- **Choose how Drawer icons look.** Settings › Drawer › Drawer icons shows them as they look in the menu bar or as each app's own icon, so the Drawer no longer mixes both styles.
- **Missing menu bar icons fill in.** Icons that were hidden before Altillo could read them are shown for a moment once, so the Drawer can show them as they look in the menu bar.
- **Menus open from the Drawer.** Apps with their own panel now open it right under the Drawer button you clicked, with the notch still open, instead of closing Altillo first.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Showing icons as they look in the menu bar needs Screen Recording; without it the Drawer shows each app's icon.
- Filling in a missing icon briefly shows that app in the menu bar once per launch.
- Some apps' standard menus can't be moved and still open under their menu bar icon.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.10.2 and disable automatic
updates temporarily in Settings. Your local Altillo data is kept unless you
explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
