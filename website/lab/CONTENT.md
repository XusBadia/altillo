## Features (8)
1. **Shelf** — Drop a file on the notch. Pick it up in another window.
   "A temporary place for the file you'll need in a moment."
2. **AI usage** — Claude, Codex, Cursor, Gemini, Copilot and five more.
   "Your quota, your pace, and when it refills — at a glance."
3. **Live agents** — "Claude Code wants to run git push." Approve or deny from
   the notch without leaving what you're doing.
4. **Calendar** — Your next meeting and a Join button, right up top.
5. **Now playing** — Pause, skip, see what's on. No app switching.
6. **Mirror** — A quick look at yourself before the call.
7. **Drawer** — Tuck away the menu bar icons you don't need to see.
   (Hiding works on macOS 26 and needs Accessibility access; on macOS 27 the
   icons stay visible in the menu bar. Say so in fine print.)
8. **Ask** — An assistant that runs on your Mac, answering from your calendar
   and clipboard. On-device by default; web search only when you allow it.

## Principles strip (3)
- **Private by design** — Usage checks go straight to each provider with the
  credential its own tool already stores. No Altillo servers.
- **Native** — Built in Swift for macOS 26. Light on battery, quiet when idle.
- **Yours to shape** — Choose which modules appear and in what order.
