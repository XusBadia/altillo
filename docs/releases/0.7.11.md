## What’s changed

- Drawer no longer draws its `│` divider next to the arrow in the menu bar.
  The arrow already marks where Drawer ends, so the divider is now an
  invisible, narrow item that still separates Drawer’s icons from the rest and
  still receives moved icons. Moves are as reliable as before.
- Two Drawer settings messages now refer to the arrow instead of the divider
  you can no longer see.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Moving an icon still borrows the pointer briefly: macOS only rearranges menu
  bar icons through a real Command-drag, and on macOS 27 the pointer stays
  visible during that drag.
- To rearrange icons by hand, Command-drag them to the left of the arrow; the
  invisible divider sits right beside it.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
