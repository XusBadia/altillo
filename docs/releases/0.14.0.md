## What’s new

- Connect your Claude or Codex account from Altillo Settings to see usage limits. Altillo keeps its own authorization in this Mac’s private Keychain and renews it independently of your CLI sessions.
- Choose Google Chrome or your system browser for sign-in. A fresh attempt starts when you press Connect, with clearer cancellation and timeout feedback.
- A redesigned return page confirms when the account is saved and offers a button back to Altillo. It supports light/dark appearance, English/Spanish and reduced motion.
- Claude recognizes current account plans. Copilot distinguishes temporary rate limiting from a rejected credential.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing installations can use **Altillo → Check for Updates…**. Altillo is signed with Developer ID and notarized by Apple.

Claude and Codex users should open **Settings → Usage** and connect their account after updating. These two collectors now use Altillo’s own session instead of an existing CLI login. Your CLI credentials remain separate.

## Known limitations

- One selected account per provider. Disconnect removes Altillo’s local authorization; manage remote revocation with the provider.
- Claude sign-in, live quota reading and persistence after restart were verified with an authorized account. Codex’s live token exchange and real refresh-token rotation remain unverified; automated tests cover these contracts. Provider endpoints and installed-client authorization may change.
- Codex sign-in needs local port 1455 available; finish any other login using that port before retrying.
- Native email accounts are still in development and are excluded from this release. Mail retains the optional Apple Mail bridge from 0.13.0.

## Need to roll back?

Quit Altillo, replace it with the DMG from [0.13.0](https://github.com/XusBadia/altillo/releases/tag/v0.13.0) and disable automatic updates temporarily in **Settings → General**. Your local Altillo data is kept unless you explicitly remove it. Version 0.13.0 reads CLI sessions for Claude/Codex rather than the authorization stored by 0.14.0.

## Support

Use **Altillo → About → Report a Problem** and include the version, build and redacted diagnostics. Never include authorization codes or tokens.
