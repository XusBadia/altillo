## What’s fixed

- Drawer now sends a real Command-key transition around its native menu-bar
  drag. macOS 27’s MenuBarAgent was ignoring mouse events that only carried the
  Command flag, so every attempted move could end with “macOS couldn't move
  this icon.”
- Moving an icon into Altillo and back to the visible menu bar has been verified
  on macOS 27 with Tailscale. Altillo still re-reads the native layout before it
  records a move as successful.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- The complete acceptance matrix still needs a separate pass on a MacBook with
  a physical notch and on macOS 26.
- Some apps own more than one menu-bar item; macOS 27 can move those items as a
  native group.

## Support

If a menu-bar icon still refuses to move, use **Altillo → About → Report a
Problem** and include the version, build and redacted diagnostics.
