Description:

```text
A place at the top of your Mac for the things you want within reach.

Shelf: drop a file on the notch, find its destination and drag it out.
AI usage: see Claude and Codex quotas and time to refill.
Live agents: approve or deny coding-agent permission requests yourself. Altillo never approves automatically.
Ask: an assistant using Apple's on-device model. Web lookups contact external services; Apple Intelligence availability is required.
Music, calendar, timers, reminders and Drawer for menu bar items.

Native for macOS 26+, including a virtual island on displays without a notch. Drawer hides selected menu bar icons on macOS 27; on 26 it lists and opens them while originals remain visible. Accessibility is required; Screen Recording is optional for actual icon images.

Free · MIT open source · Signed and notarized · Pre-1.0
No Altillo backend or app analytics. Optional usage checks present the credential already stored by the provider's own tool directly to that same provider.

Download: https://altillo.app/
Source: https://github.com/XusBadia/altillo
Privacy: https://altillo.app/privacy/
```
