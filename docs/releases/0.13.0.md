## What’s new

- **Mail in your notch, as an optional beta.** Connect Apple Mail with a rule you create in its Settings. New messages show their sender and subject; open the original message, copy a recognized sign-in code or open a recognized HTTPS sign-in link with its domain visible.
- **A short-lived inbox on your Mac.** Recent messages stay in memory for five minutes. Turning Mail off, locking the screen or sleeping clears them. Mail content is not saved to history or sent to Ask.
- **Choose which messages appear.** Filter by sender address or Mail account name and turn new-mail glances on or off. Mail is off by default on new installs and after updating.

## Install or update

Download the DMG, open it and drag Altillo to Applications. Existing users can
choose **Altillo → Check for Updates…**. The app is signed and notarized.
To connect Mail, open **Settings → Sections → Mail** and follow the setup guide.

## Known limitations

- Apple Mail must be open and receiving messages. Setup requires creating the **Altillo Mail** rule manually and choosing **Don't Apply** to previous messages. Altillo does not connect directly to Gmail or Outlook.
- This beta reads the beginning of a message and caps message/event sizes and delivery batches. It can miss codes later in the body or in a large batch. Code recognition currently handles labelled numeric codes in English and Spanish; links need a supported token parameter, with a recognized sign-in path for generic `token` links. Ambiguous candidates do not get an action.
- Messages with a body still pending can show their sender and subject; code and link actions use only the text already available.
- Setup checks the local script files. Reception is confirmed by a new message arriving; Altillo does not query Mail rules or need an Altillo → Mail Automation grant. Rules and scripts are removed manually.
- Mail glances respect Altillo's existing full-screen and interruption settings. Inspect the Mail section if a glance did not appear.
- Other modules keep their existing requirements; hiding Drawer icons requires macOS 27.

## Need to roll back?

Disable the Mail section and remove the **Altillo Mail** rule in Mail Settings.
Altillo preserves the rule and both scripts when you disconnect. Use **Show scripts**
in Altillo Settings to remove **Altillo Mail.scpt** and **Altillo Mail Bridge.scpt**
manually, after removing every rule that uses them. Then replace the app with 0.12.1.
If you already rolled back, open Mail's scripts folder to remove only those two
scripts. Other Altillo data stays on your Mac; Mail messages were held only in memory.

## Support

Use **Settings → About → Report a Problem**. Include your Altillo/macOS versions
and whether a new message reached the Mail section. Do not attach real access codes,
sign-in links or private mail content. [Mail setup guide](https://github.com/XusBadia/altillo/blob/main/docs/correo.md).
