## What’s new

- **Usage reads on one line.** On a narrower notch the refill time ("refills in 1 h 11 min") and each provider's second limit no longer break over two lines. When there's no room, the second limit drops its refill time, which stays in the tooltip.
- **A Usage panel the size of your providers.** The panel grows with the providers you have instead of always opening to its tallest, so one or two providers no longer leave empty wood below them. Longer lists still scroll.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Apps that open one of their own windows (Google Drive, say) keep it where they put it.
- Showing icons as they look in the menu bar needs Screen Recording; without it the Drawer shows each app's icon.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.10.4 and disable automatic
updates temporarily in Settings. Your local Altillo data is kept unless you
explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
