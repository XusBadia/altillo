Name: Altillo

Tagline:
```text
A shelf, AI usage and live agents in your Mac's notch
```

About the project:
```text
Altillo puts a temporary file shelf in the Mac's notch. Drop a file there, navigate to its destination, and drag it out when you're ready.

I also wanted a place to see my Claude and Codex limits and respond when a coding agent needs permission. Altillo puts those requests at the top of the screen. You choose whether to approve or deny; it never approves automatically.

The name means a small attic in Spanish: a place for the things you want within reach. It's written in Swift, free, open source under MIT, signed and notarized. It requires macOS 26 or later and creates a virtual island on displays without a notch.

Music controls, calendar, timers, reminders and an on-device assistant are also available. Ask depends on Apple Intelligence availability. Its model runs on your Mac; web lookups contact external services. Optional quota checks connect directly to the relevant provider using its existing credential, with no Altillo backend or analytics.

Drawer opens menu bar items from a compact strip. On macOS 27 it can hide those icons; on macOS 26 the originals stay visible. Accessibility is required; Screen Recording is optional for capturing the actual icon images.

This is a working pre-1.0 app. I'd like feedback on the first file drop and the agent permission flow, especially if you use an external display.

Download: https://altillo.app/
Source: https://github.com/XusBadia/altillo
```
