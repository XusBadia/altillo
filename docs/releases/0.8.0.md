## What’s changed

The Clipboard section keeps much more than text now, and it's one shortcut away.

- **Images, files and formatting.** Copied images become slips with a
  thumbnail; files copied in Finder are kept by reference (never their
  contents) and are still found if you move or rename them; formatted text
  keeps its bold, links and lists when you copy it back. ⇧-click copies without
  formatting, Space opens an image or file in Quick Look.
- **Find text in images.** The words in a copied image are read on your Mac,
  so search finds a screenshot by what it says.
- **Open it from anywhere.** ⌃⌥V opens the clipboard ready to search (choose
  another shortcut, or none, in **Settings → Sections → Clipboard**). Optionally,
  the slip you pick is pasted straight into the app you were in.
- **Leave apps out.** Pick apps whose copies are never read, on top of the
  password managers Altillo already skips.
- **Easier to read.** Filter by texts, images or files; links show their site,
  colour codes show a swatch, and the empty section lists the gestures.
- The whole Clipboard setup (shortcut, pasting, what's kept, apps left out)
  lives in its own card in **Settings → Sections**.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Pasting into the app in front needs Accessibility (macOS asks for it to
  send ⌘V to another app). Without it, picking a slip only copies it.
- The very first time Altillo reads the text in an image, macOS prepares its
  text recognition, which can take up to half a minute; after that it's
  instant.
- Images are kept in memory only, unless you keep the history after quitting;
  up to 12 images (64 MB in all). Quick Look and dragging an image out use a
  private temporary file that is removed with the slip.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it; a clipboard history
saved by 0.8.0 still opens in 0.7.x (file slips show their names; image slips come up blank).

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
