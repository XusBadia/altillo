## What’s fixed

- Clicking the date or clock in the macOS menu bar opens Notification Center when the Drawer is hiding icons, even if you move the pointer away straight after clicking.

## Install or update

Use **Altillo → Check for Updates…** or download the signed, notarized DMG below.

## Rollback and support

To roll back, quit Altillo, install [0.15.1](https://github.com/XusBadia/altillo/releases/tag/v0.15.1) and temporarily turn off automatic updates in **Settings → General**. For help, use **Altillo → About → Report a Problem** and include the version and redacted diagnostics.
