## What’s new

- **More balanced Drawer icons.** The battery stays within a single tile, while dates and status percentages use a smaller, more consistent size.
- **No more blank white tiles from invalid captures.** Opaque grayscale icons retain their details, and featureless captures fall back to the application icon. Previously cached captures are checked too.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Real menu bar icons require Screen Recording permission. Without it, Altillo
  shows application icons or system symbols.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.10.0 and disable automatic
updates temporarily in Settings. Your local Altillo data is kept unless you
explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
