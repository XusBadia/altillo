## What’s new

- Usage settings now explain how Grok, Copilot and Gemini connect, with inline steps, setup guides and commands you can copy.
- Open Antigravity directly from the connection steps when it is installed. Gemini usage comes from Antigravity, rather than the Gemini website.
- Providers with monitoring switched off now say “Monitoring off” instead of appearing to check indefinitely or showing an old active warning.
- Connection guidance and controls are available in English and Spanish and identify the actual tool to open when a session expires.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing installations can use **Altillo → Check for Updates…**. Altillo is signed with Developer ID and notarized by Apple.

## Known limitations

- Grok, Copilot and Gemini still use the sessions saved by their supported local tools. This release adds setup guidance, not a new Altillo-owned OAuth connection for those providers.
- Gemini quotas are read from Antigravity. A sign-in on gemini.google.com alone does not connect this integration.
- Claude and Codex retain the direct account connections introduced in 0.14.0. The limitations documented in that release still apply.

## Need to roll back?

Quit Altillo, replace it with the DMG from [0.14.0](https://github.com/XusBadia/altillo/releases/tag/v0.14.0) and disable automatic updates temporarily in **Settings → General**. Your local Altillo data is kept unless you explicitly remove it.

## Support

Use **Altillo → About → Report a Problem** and include the version, build and redacted diagnostics. Never include authorization codes or tokens.
