## What’s new

- **AI usage focuses on provider-reported quotas.** See the percentage used, when the quota resets, and whether the reading is current. Removed monetary balances, credit balances, token counters and spending-derived meters from the usage model, collector output, notch and Ask.
- **No exhaustion predictions.** Removed pace markers, “runs out at” forecasts and predictive alerts. Alerts still notify you when an observed quota crosses your chosen threshold, reaches its limit or refills.
- **Less billing traffic.** Cursor no longer makes credit-grant or Stripe balance requests. OpenRouter is removed from the usage catalog because its integration only reported credits and monetary spending caps.
- **Missing data stays unknown.** A malformed Claude session no longer becomes a fresh 0% reading. An authenticated Copilot plan with no finite quota clears previous quota readings without asking you to sign in again.
- **The website matches the app.** The English, Spanish and Catalan demo now shows quotas and reset times without spending balances or exhaustion forecasts.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- **Usage history starts over after this update.** Old quota snapshots and the local usage trend are not imported, because they can contain percentages calculated from monetary spending. Current quotas are fetched again and a new local history begins. Other Altillo data is unaffected.
- Providers and plans that do not report a supported quota no longer show a spending balance in its place. OpenRouter is no longer listed.
- Quota checks still rely on the provider’s own sign-in and availability. Altillo never refreshes or rewrites another tool’s credentials; failed checks retain the last quota with its original timestamp and an error state.
- Home remains a beta with the limitations described in the 0.11.0 release.

## Need to roll back?

Quit Altillo, replace it with the DMG from version 0.11.0 and disable automatic
updates temporarily in Settings → About. Usage history replaced after upgrading
is not restored by rolling back; other local Altillo data is kept.

## Support

If something fails, use **Settings → About → Report a Problem** and include the
version, build and redacted diagnostics.
