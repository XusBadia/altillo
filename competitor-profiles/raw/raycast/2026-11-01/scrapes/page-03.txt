L113: Core Features
L114: # Snippets
L115: 
L116: Snippets let you store frequently used text and insert it anywhere on your computer with just a few keystrokes. Whether it's email templates, code blocks, addresses, or emoji sequences, Snippets save you from typing the same things over and over. In v2, Snippets gain support for tagging and a new `{calculator}` 【28†dynamic placeholder】.
L117: 
L118: 【93†Snippets in Raycast†www.youtube-nocookie.com】
L119: Open Snippets by searching for "Search Snippets" or "Create Snippet" in 【4†Root Search】, or assign a hotkey for instant access.
L120: ## Creating a Snippet
L121: 
L122: To create a new Snippet:
L123:   1. Open Raycast and search for Create Snippet
L124:   2. Enter the text you want to save in the Snippet Text field. This can be plain text, formatted content, code, or any text you type repeatedly.
L125:   3. Give your Snippet a Name so you can find it later.
L126:   4. Optionally assign a Keyword to enable auto-expansion (see below).
L127:   5. Optionally add Tags to organize your Snippets into groups.
L128:   6. If you're in a Raycast team, choose an Organization to decide whether the Snippet is personal or shared with your organization.
L129: Snippet text has a maximum length of 65K characters. This limit exists for performance reasons — in practice, most Snippets are well within this range.
L130: ## Keywords & Auto-Expansion
L131: 
L132: Keywords are the real power behind Snippets. When you assign a keyword to a Snippet, typing that keyword in any application automatically replaces it with the full Snippet text. This works everywhere: in your browser, code editor, email client, chat apps, and more.
L133: ### How Auto-Expansion Works
L134: 
L135:   1. Assign a keyword to your Snippet (e.g., `!email`, `;;addr`, `/sig`)
L136:   2. Type the keyword in any text field on your computer
L137:   3. Raycast automatically replaces the keyword with your Snippet text
L138: 
L139: Choose keywords that are unlikely to be typed accidentally. Prefixes like `!`, `;;`, or `//` work well. For example, `!thanks` is safer than just `thanks`.
L140: ### Auto-Expansion Settings
L141: 
L142: You can enable or disable auto-expansion globally in Settings → Snippets. When disabled, Snippets still work — you just need to search for them in Raycast and paste manually instead of using keyword triggers.
L143: ### Keyword Character Reference
L144: 
L145: Not all characters can be used in keywords. Raycast uses certain characters as word-boundary delimiters, which means they will trigger expansion rather than become part of the keyword itself.
L146: 
L147: Characters that cannot be used in keywords:
L148:   * Backtick: ```
L149:   * Quotation marks: single quote `'`, double quote `"`, and their curly/smart variants `' ' " "`
L150:   * Whitespace: spaces, tabs, and newlines
L151:   * Other delimiters: some additional punctuation characters act as word boundaries and will trigger expansion instead of being included in the keyword
L152: 
L153: Characters that can be used in keywords:
L154:   * Letters: all Unicode letters (Latin, Cyrillic, CJK, etc.)
L155:   * Numbers: `0–9`
L156:   * Hyphen & underscore: `-` and `_`
L157:   * Math symbols: such as `+ = < >`
L158:   * Currency symbols: `$ € £ ¥` and others
L159:   * Most punctuation: including `! ; / . , @ # ~ &` (except the restricted characters listed above)
L160: 
L161: Keywords like `!email`, `;;addr`, `/sig`, and `$price` are all valid. Keywords like `my email` (contains a space) or `it's` (contains an apostrophe) are not, because the space and quote act as delimiters.
L162: ## Searching & Managing Snippets
L163: 
L164: The Search Snippets command gives you a central view of all your Snippets. From here you can:
L165: 
L166:   * Search by name, keyword, or content
L167:   * Filter by tag to quickly narrow down your collection
L168:   * Copy a Snippet to your clipboard
L169:   * Paste a Snippet directly into the active application
L170:   * Pin frequently used Snippets to the top of the list
L171:   * Edit, duplicate, or delete Snippets
L172: ## Dynamic Placeholders
L173: 
L174: Snippets support 【28†Dynamic Placeholders】 — arguments that are replaced with dynamic data when the snippet is expanded. This lets you create context-aware Snippets that adapt every time you use them.
L175: ## Tags
L176: 
L177: Snippets now support tagging. Tags let you organize your Snippets into logical groups — for example, by project, language, client, or purpose. You can assign one or more tags when creating or editing a Snippet, and then filter by tag in the Search Snippets view to quickly find what you need.
L178: 
L179: To add a tag:
L180:   1. Open the Snippet editor (create a new Snippet or edit an existing one)
L181:   2. Use the Tags field to assign one or more tags
L182:   3. Type a new tag name to create it, or select from existing tags
L183: 
L184: In the Search Snippets view, use the tag filter dropdown to show only Snippets with a specific tag. This makes it easy to manage large Snippet collections.

L187: ## Shared Snippets (Teams)
L188: 
L189: With Raycast for Teams, you can create shared Snippets that are available to everyone on your team. This is ideal for maintaining consistent messaging: support responses, company boilerplate, onboarding templates, and more.
L190: 
L191: Shared Snippets are managed from the same Search Snippets interface. They appear alongside your personal Snippets and can be filtered separately. Team admins can manage shared Snippets from the Raycast Teams dashboard.
L192: ## Importing Snippets
L193: 
L194: You can bring existing Snippets into Raycast from a file or from another text expansion tool. To import:
L195: 
L196:   1. Open Raycast and run the Import Snippets command
L197:   2. Select your file
L198:   3. Review the Snippets to be imported, then confirm
L199: ### Supported File Format (JSON)
L200: 
L201: Raycast imports Snippets from a JSON file containing an array of snippet objects. Each object supports:
L202: 
L203:   * `name` (required) — the Snippet's title
L204:   * `text` (required) — the content that gets inserted
L205:   * `keyword` (optional) — the trigger that expands the Snippet
L206: Example:
L207: 
L208:     `[
L209:       {
L210:         "name": "Personal Email",
L211:         "text": "sherlock@gmail.com",
L212:         "keyword": "@@"
L213:       },
L214:       {
L215:         "name": "Home Address",
L216:         "text": "221B Baker St., London"
L217:       },
L218:       {
L219:         "name": "Catchphrase",
L220:         "text": "Elementary, my dear Watson",
L221:         "keyword": "!elementary"
L222:       }
L223:     ]`
L224: Save the file with a `.json` extension. If your file is greyed out and can't be selected in the import dialog, it isn't in a format Raycast recognizes — convert it to the JSON structure above.
L225: ### Importing from Other Tools
L226: 
L227: Raycast can also import from other text expansion tools such as TextExpander, aText, Espanso, and PhraseExpress. Export your Snippets from those apps, then select the exported file in Import Snippets.
