## What’s new

- **Thirty-day AI usage trends.** Each provider now includes a compact local
  history so you can see whether usage is rising or falling. Altillo keeps one
  hourly percentage sample for 30 days and never stores credentials in it.
- **Pomodoro inside Timer.** Choose 25/5, 50/10 or 90/20 cycles, pause or skip
  phases, and see today’s focused time. The cycle survives relaunches and uses
  the same alerts and optional sound as the existing timers.
- **Reminders in the notch.** Add the opt-in Reminders section to see today’s
  and upcoming items, mark them complete or open the Reminders app. Permission
  is requested only when you explicitly grant it.
- **Lyrics in Now Playing.** Load plain or time-synced lyrics on demand and tap
  a line to seek. Nothing is sent until you press **Load Lyrics**; that request
  sends only the track metadata to LRCLIB, never audio or your library.
- **A width for every display.** Altillo remembers a separate open width for
  each connected screen, with one click to return a screen to the default.
- **Correct source versioning.** Development builds now show 0.10.0 instead of
  the stale 0.1.0 value, and the release script refuses to publish when the
  source and requested versions disagree.

## Install or update

Download the DMG below, open it and drag Altillo to Applications. Existing
installations can use **Altillo → Check for Updates…**. Altillo is signed with
Developer ID and notarized by Apple.

## Known limitations

- Lyrics depend on LRCLIB having a match for the track metadata supplied by
  the active player; some tracks have only plain lyrics or no match.
- The Reminders section is opt-in and needs macOS Reminders permission. Adding
  a new reminder remains in Ask or Apple’s Reminders app.

## Need to roll back?

Quit Altillo, replace it with the DMG from the previous GitHub release and
disable automatic updates temporarily in **Settings → General**. Your local
Altillo data is kept unless you explicitly remove it.

## Support

If something fails, use **Altillo → About → Report a Problem** and include the
version, build and redacted diagnostics.
